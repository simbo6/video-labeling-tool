### 本次调整

- 增加 SQLite 数据库层，统一保存用户登录、项目、导入文件、标注类型和标注记录。
- 项目表保存患者信息、视频路径、腕表数据路径、采样率、腕表开始/结束时间和信号对齐偏移。
- 标注记录和项目关联，右侧标注框展示当前项目患者信息和所有未删除标注。
- 标注记录页从数据库读取全部记录，并优先按项目腕表开始时间显示真实时间。
- 腕表信号支持加速度、角速度、肌电和 PPG；PPG 默认按 `data[7,0]` 读取，采样率默认 25 Hz。
- 波形绘制按整段数据的最大值/最小值缩放，线条加粗，避免播放时窗口缩放造成视觉跳动。
- 对齐偏移写回项目数据库，重新打开项目后自动恢复。
- 将主要函数级注释改为中文，便于后续继续维护。

### 维护方法

- 入口文件为 `main.py`，主窗口在 `app/main_window.py`。
- 数据库相关功能统一放在 `app/database.py`，新增字段时需要同步更新 `init_schema()` 和 `ensure_schema_columns()`。
- 页面逻辑放在 `app/pages.py`，不要把数据库 SQL 写到页面里，页面只调用 `AppDatabase` 方法。
- 波形、能量轴、模态滤波弹窗和整体时间轴放在 `app/widgets.py`，播放性能相关优化优先在这里处理。
- 每次改完后至少运行：

```powershell
$env:PYTHONPYCACHEPREFIX="$env:TEMP\codex_pycache_h2605124732"
python -m py_compile main.py ui_frontend.py app\__init__.py app\shared.py app\widgets.py app\pages.py app\main_window.py app\database.py
```
