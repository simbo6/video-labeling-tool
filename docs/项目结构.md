# 项目结构

## 入口

- `main.py`：程序启动入口，创建 `QApplication` 并打开主窗口。
- `ui_frontend.py`：兼容旧导入路径，只导出 `APP_QSS` 和 `MainWindow`。

## 应用代码

- `app/shared.py`：公共依赖、全局样式 `APP_QSS`、通用按钮和卡片工厂函数。
- `app/widgets.py`：可复用控件，包括腕表波形、能量轴、模态滤波弹窗、顶部时间轴。
- `app/pages.py`：页面级 UI，包括登录、项目列表、导入页、可视化页、记录页、标注页。
- `app/main_window.py`：主窗口和页面路由。
- `app/database.py`：SQLite 数据库初始化和用户、媒体文件、标注类型、标注记录的读写方法。
- `app/__init__.py`：应用包导出。

## 数据归档

- `data/mat/`：腕表 `.mat` 数据文件。
- `data/videos/`：视频文件。
- `data/app.db`：程序运行后自动创建的 SQLite 数据库文件。

## 文档

- `docs/开发记录.md`：开发记录模板和每次改动记录。
- `docs/项目结构.md`：当前文件结构说明。
- `需求文档/`：需求文档资料。

## 清理原则

新功能代码优先放进 `app/`；测试数据放进 `data/`；开发说明放进 `docs/`；运行缓存、IDE 配置、旧原型脚本和不再引用的参考脚本应删除。
